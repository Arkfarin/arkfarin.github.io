# KIYORA

**Quiet Precision** — локальный музыкальный плеер для Linux на Python и Qt Quick.
Тёмный спокойный интерфейс, собственная медиатека и независимая очередь. Без аккаунтов,
телеметрии, веб-движка и обязательного подключения к интернету.

![Экран текущей композиции](docs/screenshots/now-playing.png)

*Снимок работающего приложения; музыка и обложки в документации — синтетические тестовые
данные. При обычном запуске приложение показывает вашу коллекцию или экран приветствия.*

## Запуск

Требуются Python **3.12+** и [uv](https://docs.astral.sh/uv/).
Из каталога проекта:

```bash
uv run kiyora
```

uv создаст `.venv` и установит версии из `uv.lock`. Интернет нужен только для первоначальной
установки зависимостей. Уже установленный плеер работает офлайн: `uv run --offline kiyora`.

Без uv:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
kiyora
```

На обычной Linux-системе с рабочим графическим столом дополнительных пакетов обычно не
нужно. Нужны работающие Wayland или X11, системные библиотеки OpenGL/EGL, Fontconfig,
xkbcommon и аудиосервер PipeWire/PulseAudio. В минимальной X11-системе Qt xcb также может
потребовать `libxcb-cursor` (`xcb-util-cursor` в Arch). Qt и его плагины устанавливаются
вместе с PySide6; системный пакет Qt не заменяет Python-зависимость. Используется Noto Sans
с системным fallback; шрифты при запуске не скачиваются.

В Wayland по умолчанию используется нативный backend. Для диагностики:

```bash
QT_QPA_PLATFORM=wayland uv run kiyora
QT_QPA_PLATFORM=xcb uv run kiyora
QT_QUICK_BACKEND=software uv run kiyora
```

Последняя команда включает программный рендеринг. Он может уменьшить RSS драйвера GPU,
но его скорость зависит от разрешения экрана и CPU.

## Что работает

- Добавление нескольких музыкальных папок через стандартный диалог; фоновое рекурсивное
  сканирование, постепенное появление треков и счётчик обработанных файлов.
- Метаданные Mutagen, встроенные и внешние обложки (`cover`, `folder`, `front`, JPG/PNG),
  несколько исполнителей и дисков альбома. Unicode-пути и поиск без учёта регистра.
- Треки с пятью вариантами сортировки; альбомы; исполнители с их альбомами и треками;
  навигация по музыкальным папкам и вложенным каталогам.
- Обновление изменённых файлов, удаление исчезнувших записей, объединение перекрывающихся
  источников. При недоступном каталоге его сохранённые записи не удаляются.
- Play/Pause, Stop, Previous/Next, перемотка, громкость, Mute и переход к следующему
  элементу очереди после окончания трека.
- Уникальные элементы очереди: один трек можно добавить несколько раз. «Сейчас»,
  «Следующим», «В очередь», удаление, перемещение вверх/вниз и очистка.
- Shuffle с историей возврата; Repeat Off / All / One независимо от Shuffle.
- Now Playing с крупной обложкой, кешированным цветовым акцентом и собственной заглушкой.
- Сохранение очереди, текущей композиции и позиции, громкости/Mute, Shuffle/Repeat,
  источников, раздела, размера окна и положения, когда оконная система это разрешает.
  **Автоматическое воспроизведение после перезапуска отключено.**
- Настройка декоративных анимаций, компактная боковая панель, клавиатурный фокус,
  подписи элементов управления и уведомления об ошибках.

На этой машине реально проверены **MP3, FLAC, OGG/Vorbis, WAV и Opus**: декодированные
аудиобуферы, продвижение позиции, пауза, перемотка и продолжение. Выход при тестировании
был заглушён на уровне приложения. Это не обещание воспроизведения любого повреждённого
файла, профиля кодека или контейнера. Сканер также распознаёт M4A/AAC, AIFF и WMA,
но их воспроизведение здесь не проверялось.

## Управление

1. На первом экране нажмите «Добавить музыкальную папку».
2. Нажмите ▶ у трека или дважды щёлкните по строке. Открыть альбом можно щелчком по карточке.
3. Меню ⋯ или правая кнопка на треке предлагает способы добавления в очередь.
4. Кнопка очереди справа внизу открывает список с управлением порядком.
5. Нажмите на обложку/название слева внизу, чтобы открыть Now Playing.
6. Кнопка обновления повторно сканирует источники. Удаление источника в настройках
   изменяет только медиатеку, **никогда не удаляет музыкальные файлы**.

Клавиши: `Ctrl+O` — добавить папку, `Ctrl+Space` — Play/Pause, `Esc` — свернуть Now Playing /
закрыть очередь. Мультимедийные Play/Next/Previous работают, когда их события получает окно.
Это не глобальная интеграция MPRIS.

## Устройство проекта

- `core/audio.py`: заменяемая граница `AudioEngine` и Qt Multimedia backend
  (`QMediaPlayer` + `QAudioOutput`). Только сигналы, без опроса позиции таймером.
- `core/queue.py`: порядок воспроизведения, идентичность элементов, история Shuffle и Repeat.
- `core/persistence.py`: единственный фоновый писатель сессии; новые снимки объединяются,
  чтобы не накапливать задания. Сохранение раз в 10 секунд, после важных действий и при выходе.
- `library/`: SQLite, SQL-репозиторий, Mutagen, сканирование, кеш обложек и изменение источников.
  Каждый поток открывает собственное SQLite-соединение; WAL и транзакции защищают данные.
- `models/`: `QAbstractListModel`, асинхронные страницы по 100 записей и модель очереди.
  QML-роль `item` — словарь строки: `id`, `title`, `artist`, `album`, `durationText`,
  `coverUrl`, `thumbUrl` и поля сущности. В очереди добавлены `entryId`, `trackId`, `current`.
- `controllers/`: действия интерфейса и координация моделей, аудио, очереди и сканера.
- `ui/qml/`: общая тема, переиспользуемые компоненты, страницы и виртуализированные
  ListView/GridView. QML не выполняет SQL и не управляет QMediaPlayer напрямую.

Сканирование и изменения источников используют один worker, запросы — максимум два,
сохранение сессии — один. Данные загружаются страницами; изображения декодируются в фоне,
на диске сохраняются варианты до 720 px и миниатюры до 128 px. QPixmapCache ограничен
24 МиБ, QML Image не сохраняет все использованные картинки в глобальном кеше.
Размер текстур ограничивается `sourceSize`, а число делегатов — виртуализацией.
Сканер не проходит символьные ссылки на каталоги, предотвращая циклы; пути файлов канонизируются.

В SQLite есть `music_sources`, `tracks`, `albums`, `artists`, `track_artists`,
`source_tracks`, `queue_entries`, `playback_state` и индексы. Тестовый аудиодвижок позволяет
проверять очередь/контроллер/UI без физического звукового устройства.

## Данные

Пути выбирает `QStandardPaths`. Обычно в Linux:

- база: `~/.local/share/KIYORA/KIYORA/library.sqlite3`;
- обложки: `~/.cache/KIYORA/KIYORA/covers/`;
- настройки QSettings: `~/.config/KIYORA/KIYORA.conf`.

Переменные XDG могут изменить эти пути. Для изолированного запуска с собственной базой,
кешем и настройками используйте:

```bash
uv run kiyora --data-dir /tmp/kiyora-sandbox
```

## Ограничения первой версии и следующий релиз

- Изменения файлов отслеживаются при ручном пересканировании; постоянного watcher нет.
- При ошибке воспроизведение останавливается с уведомлением. Автоматическое бесконечное
  пропускание повреждённых файлов исключено; можно перейти к следующему вручную.
- Перемещение очереди выполнено кнопками вверх/вниз, без drag-and-drop. «Сейчас» добавляет
  выбранный трек в самостоятельную очередь, а не превращает список медиатеки в очередь.
- Каталог с недоступными вложенными папками обрабатывается консервативно: удаление записей
  откладывается до успешного полного обхода. Симлинки на папки не обходятся.
- Дисковый кеш обложек пока не имеет пользовательской квоты; старые варианты после смены
  обложки могут оставаться на диске. Это не означает загрузку этих изображений в RAM.
- В тестовой Wayland-сессии RSS в покое выше желаемых 200 МиБ. См. точные измерения ниже.
- Нативный Wayland/Hyprland проверен; отдельные KDE Plasma, X11 и Windows-сеансы не проверены.
  В Wayland положение окна определяет compositor. Субъективное качество звука не оценивалось.
- Нет MPRIS, редактирования тегов, DSP/эквалайзера, онлайн-сервисов и других исключённых
  из первой версии функций.

Для следующего релиза: MPRIS, управление дисковым кешем, drag-and-drop очереди,
дополнительная проверка реальных больших коллекций, Plasma/X11 и профилирование GPU RSS.
Разделение движка, очереди и UI позволяет добавить новые аудиовозможности без их переписывания.
