Проверено локально 18 октября 2026 года: Linux, Node.js 26.11.1, npm 12.2.0,
Playwright Chromium. Исходник для сравнения — коммит `ebd7824`, его `dist/`
был сохранён отдельно до изменений.

## Функциональность

Браузерные сценарии проверяют переход из карточки, прямую загрузку страниц,
историю, неизвестный slug/маршрут, оглавление и якоря, переключение темы,
системные изменения, сохранение выбора и переключение логотипа Luminesk.
Проверены успешное копирование, отказ Clipboard API с выделением кода,
копирование Telegram и поведение при заблокированном localStorage.

Меню проверено на открытие, Escape с возвратом фокуса, клик вне меню, переход
по ссылке и смену брейкпоинта. Проверены skip-link, видимый клавиатурный focus,
сворачивание оглавления на телефоне, reveal-анимация и изменение reduced motion
во время работы страницы. Ошибок JavaScript/гидратации в сценарии маршрутов нет.

Главная и оба проекта проверены на ширинах **320, 390, 768, 1024, 1440, 1920 px**
в обеих темах: горизонтального переполнения нет. axe (WCAG 2 A/AA и 2.1 AA)
проверяет все три страницы при 390 и 1440 px в обеих темах; нарушений не обнаружено.
Это автоматизированная проверка, а не заявление о полной сертификации доступности.

В dev-режиме дополнительно открыты главная и обе страницы, проверена выдача
оригинального Markdown с `Content-Type: text/markdown`. Шрифты загружаются локально.
Снимок KIYORA, оба логотипа и внешние бейджи Luminesk загружены в браузере.
Оригиналы `.md` после сборки побайтово совпадают с исходниками.

Проверка `test:build` создаёт изолированную временную копию, добавляет третий проект
через JSON/Markdown, собирает сайт для `/portfolio/` и открывает его на обычном
файловом HTTP-сервере. Проверяются GFM-таблица, task list, уникальные якоря,
TypeScript-подсветка, относительная ссылка, локальная картинка, карточка,
маршрут, оригинальный Markdown, мобильная навигация и отсутствие ошибок.
Компоненты в этой проверке не меняются. Повторный slug приводит к отказу сборки.

Сняты и просмотрены страницы до/после. Дополнительно сопоставлены
`getBoundingClientRect()` всех четырёх секций главной и footer при одинаковой
высоте viewport 1000 px, загруженных шрифтах и reduced motion:

| Ширина  | Максимальное отличие x/y/width/height |
| ------- | ------------------------------------- |
| 390 px  | 0 px                                  |
| 768 px  | 0 px                                  |
| 1024 px | 0 px                                  |
| 1440 px | 0 px                                  |
| 1920 px | 0 px                                  |

Это проверка геометрии главной, а не утверждение о побайтовом совпадении всех
скриншотов. README теперь рендерит GFM-пайплайн; сохранены компоновка, типографика,
иллюстрации и содержимое, оформление токенов кода соответствует Highlight.js.
Серый цвет комментариев в светлой теме изменён с `#6c6b65` на `#66655f`:
исходный давал контраст 4.43:1 на фоне блока кода и не проходил axe.

## Производительность и архитектурные ограничения

Production-сборка: основной JavaScript около **89 kB gzip**, отдельный модуль
страницы проекта/Markdown около **128 kB gzip**. Тексты проектов — отдельные
модули примерно 3.2 и 5.7 kB gzip. Основной CSS около 5.4 kB gzip, CSS проекта
около 2.7 kB gzip. В браузере подтверждено, что главная не запрашивает модуль
Markdown и тексты проектов. Грамматики подсветки ограничены восемью языками.

React увеличивает JavaScript относительно исходного vanilla-сайта; преимущества
рефакторинга — модульность, типизация и воспроизводимость. Полный HTML выдаётся
сразу, включая README, что отдельно проверено с отключённым JavaScript.
Промежуточная сборка с полным набором грамматик имела модуль проекта около
173 kB gzip; ограниченная регистрация снизила его до 128 kB gzip.
Это анализ локальных сборок и загрузки модулей, не замер Lighthouse или полевых
Core Web Vitals.

ESLint 9 выбран из-за заявленных peer-зависимостей `eslint-plugin-jsx-a11y`;
форсирование несовместимой установки ESLint 10 не используется.
Тесты выполнены в Chromium; Safari/Firefox и удалённый production-хостинг
в эту локальную проверку не входят. Deployment-инструкции приведены в README;
публикация сайта не выполнялась.
