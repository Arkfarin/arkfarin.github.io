# Архитектурный аудит

Исходное состояние: коммит `ebd7824`. До изменений в репозитории были только
`content/projects.json`, два исходных Markdown и готовый сайт `dist/`.
README.md, START_HERE.md, package.json, конфигурации, исходный Python-генератор
`scripts/build-projects.py` отсутствовали. Проверены дерево Git и фактические файлы.
Поэтому анализировать или сохранять несуществующий генератор невозможно.

## Что работало

Главная: боковая навигация, адаптивное меню, системная/сохранённая тема,
анимация заголовка и появления секций, две карточки, социальные ссылки,
копирование Telegram. Страницы `/projects/kiyora/` и `/projects/luminesk/`:
README, подсветка, копирование с выделением при отказе clipboard, оглавление,
якоря, скачивание оригинального Markdown, переход к соседнему проекту.

Зависимости: HTML → styles.css + projects.css + app.js; страницы проектов
дополнительно → project.js. Шрифты и иллюстрации локальны; значки статусов
Luminesk загружаются с shields.io. Исходники README ссылаются на файлы
соответствующих GitHub-репозиториев. Сборочных зависимостей в дереве не было.

## Проблемы

- Исходная сборка невоспроизводима; готовый HTML смешивает данные, шаблон и README.
- Повторяются навигация, тема и оболочка страниц.
- Глобальные CSS содержат стили несуществующих вкладок, постеров и image-dialog.
- Цвета дублируются; переключение логотипов и reduced motion используют !important.
- DOM-обработчики не имеют lifecycle cleanup, данные социальных сетей повторяются.
- Привязка README к локальным картинкам существует только в готовом HTML.
- Устаревший og:url указывает на другой домен.

## Целевая структура

React + TypeScript strict, Vite, React Router, CSS Modules. Общие токены темы
и типографика отдельно от оформления компонентов. Главная разбита на секции;
Markdown и подсветка загружаются вместе со страницей проекта, отдельно от главной.
JSON остаётся единственным каталогом проектов, Markdown — единственным источником
документации. Статические страницы и оригиналы Markdown выпускает единая сборка Vite.
Существующие шрифты, рисунки, тексты и брейкпоинты сохраняются.

GSAP, Lucide, Tailwind и глобальный state manager не нужны: CSS покрывает имеющиеся
анимации, исходный интерфейс использует типографические стрелки, а состояние локально.
Python и внешняя система генерации не вводятся.
